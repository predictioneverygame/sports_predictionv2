LINE 後台設定（Flex 二級選單）

  1. 部署 Webhook：npm run supabase:deploy:line-webhook
  2. LINE Developers → Messaging API → Webhook URL 設為 areas.json 內的 webhook，並啟用 Webhook
  3. 圖文選單上傳 main.png，三格動作改Postback（非連結）：m=t、m=w、m=h
  4. Secrets 需有 LINE_CHANNEL_SECRET 與 LINE_CHANNEL_ACCESS_TOKEN（或 ID+SECRET）
